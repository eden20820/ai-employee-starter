# AI Employee Starter

A focused MVP for an AI workforce platform: describe the employee you need, review the generated employee plan, then connect tools and deploy.

## Current scope

- Landing page
- AI Workforce dashboard
- Create Employee flow
- Employee Plan preview

## Run locally

```bash
npm install
npm run dev
```

Then open `http://localhost:3000`.

## Next milestone

Connect Supabase for authentication/database, then replace the mocked Employee Plan with structured AI generation.
